核查依据

事务与重复请求

数据库唯一约束应对应业务幂等域。捕获重复键后，要考虑失败事务的状态、提交可见性和相同请求标识的参数冲突；简单地在同一个失败事务中继续查询并不可靠。参阅 Spring 事务传播文档。

Java 21 虚拟线程

虚拟线程帮助承载大量等待 I/O 的并发任务；它们不会扩大数据库、CPU 或模型接口的容量，也不能代替并发限额。正文保留 Java 21 的讨论范围，不把后续 JDK 的行为直接套到 Java 21。参阅 Oracle Java 21 虚拟线程文档。

沙箱与工具权限

模型提出行动，运行时校验并执行。仓库内容不是指令来源；测试命令本身也可能运行仓库代码。容器安全策略只是多层防护的一环。参阅 Kubernetes Pod Security Standards。

修复评测

SWE-bench 根据真实代码库的问题描述评估补丁，使用独立执行环境检查结果。站内的通过率计算器展示固定预算下的教学模型，不代表任何真实模型或平台成绩。参阅 SWE-bench 官方说明。

使用边界

小说中的时间、监控数字、公司、任务结果和个人经历均为叙事或教学示例。示例没有经过完整生产验收。章末练习用于自测理解，不构成能力认证。
